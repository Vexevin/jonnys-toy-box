How a toy gets on the box

  1. A public URL exists — today that is often a grok.me prototype.
  2. The toy gets a dedicated page the same day. The first button is Open prototype.
  3. A copy on GitHub or itch unlocks Source.
  4. A file you can keep unlocks Download or Install.
  5. Ideas without a URL stay off the shelf. Empty slots are the coming-soon.
