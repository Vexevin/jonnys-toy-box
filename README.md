# Jonny's Toy Box

Public shelf for games, apps, and tools by Jonny Vexevin Light.

Live site (after GitHub Pages is enabled on `main` / root):

https://vexevin.github.io/jonnys-toy-box/

## Rule

A toy with a public URL belongs on the shelf. HTML is a prototype. Open comes first. Download waits for a keepable file.

## Enable Pages

Repository Settings → Pages → Deploy from branch → `main` → `/ (root)`.
